## Current Projects

### [mechanism_viewer v0.1.1](https://github.com/Ti-n-a/mechanism_viewer)

🎉 Just released **my own** Python package on [PyPI](https://pypi.org/project/mechanism-viewer/) ! 🎉

`mechanism_viewer` is a Python package that offers tools to explore and diagnose missing patterns in tabular data. In other words, any data scientist can understand why their data has missing values.

It includes visualization tools, statistical diagnostics, imputation diagnostics, and synthetic data generation tools.

Check it out:
* [PyPI](https://pypi.org/project/mechanism-viewer/)
* [Repository](https://github.com/Ti-n-a/mechanism_viewer)
* [Documentation](https://ti-n-a.github.io/mechanism_viewer/)
